# ZAPRET AUTOPILOT

**Русский** | [English](README.en.md)

Программа сама ставит, чинит, настраивает и включает [zapret от Flowseal](https://github.com/Flowseal/zapret-discord-youtube),
чтобы работали Discord и YouTube.

### [⬇ Скачать zapret-autopilot.zip](https://github.com/Microb4ek/zapret-autopilot/releases/latest/download/zapret-autopilot.zip)

Сам zapret в архиве не лежит: программа всегда скачивает его последнюю версию с GitHub Flowseal.

## Как пользоваться

1. Скачайте архив по ссылке выше и распакуйте его целиком: правой кнопкой → «Извлечь всё».
2. Откройте папку `zapret-autopilot` и дважды щёлкните `zapret-autopilot.bat`.
   - Если Windows спросит «Запустить этот файл?», нажмите «Запустить».
   - Если появится синее окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
   - На вопрос о разрешении вносить изменения ответьте «Да».
3. Нажмите **Enter** и подождите 5–10 минут.

Дальше программа делает всё сама:
- находит zapret на компьютере, а если его нет — скачивает последнюю версию и ставит в `C:\zapret`;
- если zapret повреждён (например, антивирус удалил файлы), переустанавливает его;
- проверяет все настройки (стратегии) и выбирает ту, что лучше всего работает у вашего провайдера;
- включает обход и делает так, чтобы он включался сам при каждом запуске компьютера;
- кладёт на рабочий стол ярлык **«Zapret»**. Скачанный архив после этого можно удалить.

Когда что-то перестанет работать, откройте ярлык «Zapret» и выберите **«Что-то не работает? Починить и настроить заново»**.

На панели задач будет свёрнутое окно «zapret». Не закрывайте его: это и есть обход.

## Режим АВТО и ручной режим

По умолчанию включён **режим АВТО**: ничего нажимать не нужно.
- **Первый запуск или поломка.** Программа 10 секунд ждёт, вдруг вы захотите открыть настройки, а потом сама всё устанавливает, чинит и настраивает.
- **Обход выключен.** Программа сама его включает и через 15 секунд закрывается.
- **Обход уже работает.** Открывается обычное меню.

Любая клавиша во время обратного отсчёта оставляет окно открытым. Единственный вопрос, который может появиться в режиме АВТО, — про исключение в Защитнике Windows (его можно отключить в настройках, см. ниже).

**Ручной режим** всегда показывает меню и спрашивает перед установкой, обновлением, починкой и удалением мешающих программ.

## Настройки

Пункт **5** на главном экране. Изменения сохраняются сразу.

| Настройка | Варианты (по умолчанию — первый) |
|---|---|
| Режим работы | АВТО / РУЧНОЙ |
| Папка для установки zapret | `C:\zapret` или любая другая. Если zapret уже установлен, программа предложит перенести его туда вместе с автозапуском и ярлыками |
| Ярлык на рабочем столе | да / нет |
| Ярлык в меню «Пуск» | нет / да |
| Включать обход при запуске Windows | да / нет |
| Обновлять zapret | только если перестал работать / всегда ставить последнюю версию / никогда |
| Исключение в Защитнике Windows | спрашивать / добавлять без вопроса / никогда не добавлять |
| Чистить кэш Discord при настройке | да / нет |
| Удалять мешающие программы (GoodbyeDPI и др.) | да / нет |
| Обязательные сервисы | все / любой набор из Discord, YouTube, Google, Cloudflare. Например, если нужны только Discord и YouTube, программа не будет обновлять zapret из-за того, что не открывается Google |
| Копировать программу в папку zapret | да / нет |

## Что делается автоматически

| Ситуация | Что делает программа |
|---|---|
| zapret на компьютере нет | Скачивает последнюю версию с GitHub в папку из настроек (`C:\zapret`) |
| Не хватает файлов zapret | Переустанавливает его начисто, ваши списки `*-user.txt` сохраняются |
| Файлы пропадают сразу после установки | Объясняет, что это антивирус, и по настройке спрашивает (или сразу добавляет, или не трогает) исключение в Защитнике Windows |
| Ни одна стратегия не открывает все обязательные сервисы | Если на GitHub есть версия новее — обновляется и проверяет заново; если нет — включает лучшую из имеющихся |
| Не работает вообще ничего, а zapret лежит в папке с русскими буквами или в OneDrive | Ставит чистую копию в папку из настроек и проверяет заново |
| Тесты не запустились | Включает стандартную `general.bat` |
| Установлена служба zapret, GoodbyeDPI и т.п. | Удаляет их: они мешают |

Перед каждым обновлением или починкой старая папка сохраняется. Вернуть её можно в «Меню для опытных» → «Откатить обновление».

## Файлы

| Где | Что |
|---|---|
| `zapret-autopilot.bat` | Запуск. Сам просит права администратора |
| `autopilot.ps1` | Вся логика |
| `<zapret>\autopilot\` | Сюда программа копирует себя; на эту копию указывает ярлык «Zapret» |
| `C:\ProgramData\zapret-autopilot\settings.json` | Настройки |
| `C:\ProgramData\zapret-autopilot\state.json` | Память: папка zapret, лучшая стратегия, результаты проверки |
| `C:\ProgramData\zapret-autopilot\last-run.log` | Отчёт о последнем запуске — пригодится, если что-то пошло не так |
| `C:\ProgramData\zapret-autopilot\backup\` | Три последние копии zapret для отката |

## Как устроена проверка

1. **Подготовка.** Останавливается текущий обход; служба `zapret` (service.bat → Install Service) удаляется.
2. **Диагностика.** Те же проверки, что service.bat → Run Diagnostics, но без вопросов.
   Включаются TCP timestamps, запускается BFE, удаляется зависшая служба WinDivert.
   Конфликтующие обходы удаляются и кэш Discord чистится, если это включено в настройках.
3. **Тесты.** Запускается родной `utils\test zapret.ps1` в режиме Standard → All configs.
4. **Выбор.** Стратегия считается рабочей, если на ней открываются все адреса обязательных сервисов из `utils\targets.txt` (по умолчанию всех: Discord, YouTube, Google, Cloudflare).
   Из нескольких рабочих выбирается та, у которой больше успешных запросов.
5. **Запуск** лучшей стратегии (свёрнуто) и автозапуск через задачу планировщика `zapret-autopilot`. Задача срабатывает при входе в Windows, с правами администратора.

## Для опытных

Цифра **9** на главном экране открывает полное меню: отдельные диагностика и тесты, таблица результатов, переустановка, откат, выбор папки.

Команды без меню:

```
zapret-autopilot.bat auto       сделать всё без вопросов (даже в ручном режиме)
zapret-autopilot.bat menu       меню для опытных
zapret-autopilot.bat settings   настройки
zapret-autopilot.bat cycle      диагностика -> тесты -> запуск лучшей
zapret-autopilot.bat start      включить запомненную лучшую стратегию
zapret-autopilot.bat stop       выключить обход
zapret-autopilot.bat diag       только диагностика
zapret-autopilot.bat test       только тесты
zapret-autopilot.bat rollback   откатить обновление zapret
```
